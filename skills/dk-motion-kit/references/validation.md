# 验证与性能

## 自动检查

仓库根目录 npm ci、npm test、npm run build。几何测试覆盖边界、镜像、透视往返和退化投影。skill 使用 skill-creator 的 quick_validate.py 校验。create_starter.py 应在空目录成功生成，并拒绝覆盖非空目录。

## 浏览器验收

在真实 Chrome 中反复刷新而不是只看热更新；检查宽屏、常规笔记本、矮屏和手机。观察入画是否越界、主文字是否被遮挡、末帧是否跳动；中途调整尺寸。连续点四个方向，保留悬浮压力，检查背面鼠标高光与点击区域。检查开场未完成时滚动、光条回程和交接后是否闪烁；滚回顶部再向下。

测试键盘 Tab/Enter/Escape、弹层外点击关闭和焦点恢复；触摸不依赖 hover。开启减少动态效果，包括开场中途切换。切换中英、深浅主题，确认不重播全页。测试空账号、头像缺失、剪贴板失败与分享取消。

## 性能取舍

先量构建体积和运行行为，不为分数重构。海报绘制按需加载；二维码原库不要在首屏重复打包；离屏停止装饰循环。避免每帧强制布局和大面积 filter/backdrop-filter。GPU 动画也有合成成本，will-change 只给必要元素，少量设备性能不能证明所有设备流畅。

GitHub Pages 是静态托管，并不替浏览器执行动画。优化目标是下载、主线程、绘制与合成。publicUrl 与 BASE_PATH 应对应最终部署地址；构建成功不等于线上验证成功。
